# 我是大收藏家 (Big Player)

> **种植 · 赌核 · 收藏**
> 
> *“你种下的不是核桃，是下一件藏品 —— 把一棵核桃树，种成一件国宝。”*

一款新国风写实手绘质感、融合轻度策略解谜的**模拟经营与国宝收藏养成游戏**（移动端/桌面端全自适应）。

---

## 📖 游戏核心世界观与玩法闭环

你继承了一片荒废的南山核桃园。通过调整台地的海拔、水土、光照、温湿度与微量元素，种出形态各异的文玩核桃；亲手敲开青皮，赌出稀有异形与多棱变异；再与性格各异的名流收藏家周旋交易，一件件换回古代名画、春秋名剑、官窑瓷器，最终建成属于自己的传世私人博物馆。

    F --> A

## 🌰 八大核心特色系统

### 1. 台地微气候系统 —— 用「土地」组合出核桃
- **三层种植条件**：
  - **Ⅰ 结构条件**：海拔（低地/丘陵/高山/雪线）、土壤类型（沙土/壤土/黏土/岩土）；
  - **Ⅱ 环境条件**：湿度、温度、光照、水源（雨水/溪水/山泉/雪水）；
  - **Ⅲ 消耗条件**：有机肥、磷肥、钾肥、硼元素（专门冲多棱异形）。
- **适生匹配度与品质系数**：
  - 严格实现 GDD 15.3 节加权算法（海拔20%、土壤15%、湿度15%、温度15%、光照15%、水源10%、养料10%）。
  - 品质系数阶梯保底机制（$\ge 35$ 保底三棱，$\ge 55$ 保底四棱，$\ge 70$ 保底五棱，$\ge 85$ 保底六棱；传说异品纯概率不设保底）。

### 2. 物理开核工坊 —— 把「赌」做成一门手感
- **手法与工具**：
  - **小铜锤**：稳健敲击，保形度 ~94%；
  - **文玩夹**：均匀施压，出核迅捷，保形度 ~86%；
  - **银挑针**：精细轻撬，专攻细微异桩，保形度 ~96%。
- **交互与表现**：青皮剥离、裂纹沿棱线蔓延、Web Audio 合成爆裂脆响与真机震动触感，伴随金紫光效揭晓边宽、肚径、高度、净重、桩型与纹路。

### 3. 五维配对与品相鉴定
- **五维配对算法**：尺寸差（25%）、桩型（20%）、纹路（25%）、皮质色泽（15%）、棱数一致性（15%）。
- **成双成对**：配对度 $\ge 85\%$ 判定为「成双成对」，$\ge 95\%$ 为「天造地设」，装入定制红木锦盒身价暴涨 2.5 ~ 4 倍！
- **品相鉴定证书**：送鉴名家，获取凡品、良品、上品、珍品、神品等朱砂烫印证书。
- **盘玩包浆**：随时摩挲盘玩，积累盘玩火候与包浆度，通体光华玉化。

### 4. 私人典藏博物馆
- **三间传世展厅**：文玩核桃厅、翰墨书画厅、金石瓷器厅。
- **展位与镇馆之宝**：格子制展架，每厅设中央唯一“镇馆之位”，赋予全馆额外声望与铜钱收益加成。
- **古物除尘与保养**：收录的古画与古剑自带岁月破损与陈旧状态，消耗矿物油与羊毫一键除尘打蜡，恢复精品光泽。

### 5. 聚宝行与春秋拍卖大会
- **NPC 交易市集**：通货刘掌柜、三棱赵把头、异形孙猎人等常驻行商，按供需特性加价收购。
- **春秋实时拍卖大会**：
  - 玩家将珍品送拍，设置托底保留价（低于保留价流拍保本）；
  - 4~8 位具备独立预算、收藏偏好与叫价风格的 NPC（老砚台稳重、铸剑翁激进、西洋客压哨绝杀）实时举牌喊价；
  - 玩家亦可在买家席举牌加价捡漏。

### 6. 名士雅集与飞鸽传书
- **五位执念收藏家**：
  - **老砚台**：爱四棱及以上端方核桃 $\rightarrow$ 兑换《快雪时晴帖》、《游春图》、《蜀素帖》；
  - **铸剑翁**：喜高海拔雪线五棱奇核 $\rightarrow$ 兑换越王勾践古剑、龙泉七星剑、汉代环首刀；
  - **瓷痴**：唯收配对锦盒 $\rightarrow$ 兑换宋代汝窑弦纹樽、成化斗彩鸡缸杯、元青花梅瓶；
  - **西洋客**：求超大霸王果与异品 $\rightarrow$ 兑换日内瓦金怀表、老坑帝王绿佩；
  - **园主旧友**：感念故情，收两棱普核 $\rightarrow$ 归还宣德桥耳炉、提供稀有良种。
- **飞鸽传书**：藏品背后的叙事信、线索信与多选项回信，提升好感度并领受随信厚礼。

### 7. 24 节气流转与鲁班技艺阁
- **24 节气环境修正**：立春至大寒全年流转，动态修正台地温湿度光照，刷新当季限定品种（清明·雨前细纹、大暑·旱生铁皮、白露·白露大果、大寒·雪线异棱）。
- **五大技艺专精**：神农育种、鲁班巧劲、火眼金睛、古物天工、富甲商道。

### 8. 收藏家协会周评比联赛
- **共享任务池**：配对委托（30分）、品种培育（20分）、异形开核（18分）、原料提交（10分）、参观点赞（6分）。
- **策略博弈**：消耗元宝任务分值翻倍，10家虚拟协会同组排行榜，每周日前三晋级、后三降级。

## 🛠️ 技术栈

- **框架**：React 18 + TypeScript + Vite
- **样式**：Tailwind CSS（新国风沉浸暖色系、茶金与朱砂配色）
- **图标**：Lucide React
- **动效**：Canvas Confetti + CSS3 物理模拟
- **音效/触觉**：Web Audio API 纯合成（无外部大音频加载延迟）+ Navigator Vibrate 震动触感
- **持久化**：LocalStorage 实时自动存档（防断电丢失）
- **单元测试**：Vitest

## 🚀 快速启动指南

### 1. 环境准备
确保已安装 Node.js (推荐 v18+) 与 pnpm。

### 2. 安装依赖
```bash
pnpm install
```

### 3. 运行本地开发服务器
```bash
pnpm dev
```
打开浏览器访问 [http://localhost:3000](http://localhost:3000) 即可开始游玩。

### 4. 运行算法与数值验算测试
```bash
pnpm test
```

### 5. 生产构建打包
```bash
pnpm build
```
